# VerSaTrack Board

An open-source STM32F407 development board designed for industrial and IoT applications.

## Features

- STM32F407VGT6
- W5500 Ethernet
- ESP32-C3 Wi-Fi
- NEO-6M GPS
- USB Type-C
- microSD Card
- Dual SPI Flash
- 2.4" SPI TFT LCD
- Altium Designer Project
